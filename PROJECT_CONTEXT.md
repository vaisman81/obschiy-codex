# PROJECT_CONTEXT.md

## Назначение рабочей папки
`C:\Codex\Общий` содержит смешанные рабочие задачи: Python-утилиты, Node-скрипты, веб-портал `vm_portal`, инфраструктурные и системные артефакты.

## Ключевые зоны
- `C:\Codex\Общий\vm_portal` - локальный портал (backend: `server.py`, frontend: `public/`).
- `C:\Codex\Общий\build_*.py` - Python-скрипты генерации/аналитики отчётов.
- `C:\Codex\Общий\build-*.mjs` - Node/ESM скрипты отчётности/сборки.
- `C:\Codex\Общий\Мелкие_проекты` - разовые и тематические подпроекты.

## Что важно не ломать
- Контракты данных для `vm_portal/data/snapshots/*` (`vsphere.csv`, `veeam.csv`, `analysis.json`).
- Совместимость скриптов отчётов с текущими именами файлов и кодировками.
- Рабочие пути Windows и русскоязычные имена директорий.

## Базовые команды
- Python syntax check: `python -m py_compile <file.py>`
- Node syntax check: `node --check <file.mjs>`
- Запуск портала: `C:\Codex\Общий\vm_portal\run_portal.bat`

## Ограничения и безопасность
- Не печатать секреты/токены/пароли/куки в ответах.
- Перед рискованными системными действиями (драйверы, сеть, удаление, reset) запрашивать подтверждение.
- Для операций с внешними источниками фиксировать источник и дату проверки.

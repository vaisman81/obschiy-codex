# Example 01 - Bugfix Template

## Входной запрос
Почини ошибку в `vm_portal/server.py`: список ВМ иногда пустой после импорта.

## Ожидаемое поведение агента
1. Уточнить цель одной фразой.
2. Проверить поток данных: import -> sqlite -> API -> frontend.
3. Сделать минимальный фикс без рефакторинга всего модуля.
4. Запустить проверку синтаксиса и smoke-test.
5. Вернуть отчёт в формате 1-4.

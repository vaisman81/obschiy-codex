# DONE_CHECKLIST.md

## Definition of Done
- [ ] Задача переформулирована одной фразой.
- [ ] Для нетривиальной задачи дан план 3-7 шагов.
- [ ] Изменены только релевантные файлы.
- [ ] Выполнены релевантные проверки (test/lint/typecheck/smoke).
- [ ] Если проверки не выполнены, явно указана причина.
- [ ] Указаны точные пути изменённых файлов.
- [ ] Нет утечки секретов в ответе.
- [ ] Итог оформлен в формате 1-4 (что сделано, почему, как проверено, риски).
